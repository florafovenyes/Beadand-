# Beadandó

A választott témám a következő: 
3. Saját mini könyvtári nyilvántartó program
Készítsünk helyi fájlokra épülő egyszerű könyvnyilvántartó programot.
Lehessen új könyvet felvenni, listázni, keresni, módosítani vagy törölni.
Az adatokat tároljuk .csv vagy .json fájlban.
Extra ötlet: kölcsönözhetőség vagy státusz mező kezelése.

A program lehetőséget nyújt arra, hogy új könyveket vigyünk fel  az adatbankjába (ami nem más, mint egy .csv vagy .json kiterjesztésű fájl) Cím, szerző, ISBN, Kiadás éve és oldalszám, kölcsönzési státusza szerint. Majd a már kész adatbankokból visszakeresni is tudunk, konkrét példányt (szerző, cím, isbn alapján), vagy az egész adatbank tartalmát lekérdezhetjük. Továbbá lehetőségünk van a már rögzített könyvek adatait megváltoztatni (módosítani), illetve adott könyveket törölni is. Emellett statisztikát is kérdezhetünk le: hány könyv van a fáljban, hány ezek közül ami kölcsönözhető, kölcsönzött vagy nem kölcsönözhető. Illetve ki is tudunk lépni a programból. 

Futtatása: nyissuk meg a beadandó requestet pycharm nevű programban, és futtassuk a main nevű fájlt.
